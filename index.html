Браузер не поддерживает требуемые возможности

Для работы FFmpeg.wasm и Whisper нужен SharedArrayBuffer. Обычно его подключает coi-serviceworker.js, который лежит рядом с этой страницей — но сейчас он не зарегистрировался. Возможные причины:

  • страница открыта по file:// (нужен http(s)://, можно localhost);
  • приватный/инкогнито режим, в котором отключены service workers;
  • файл coi-serviceworker.js не задеплоен рядом с index.html.

Запуск локально (Node.js)

Простейший способ открыть и index.html, и coi-serviceworker.js с одним сервером:

npx serve -l 8080

Откройте http://localhost:8080 — service worker зарегистрируется и страница автоматически перезагрузится с включённым cross-origin isolation.

Если service worker недоступен — альтернатива с реальными заголовками

Запустите Node-сервер, который сам выставляет COOP/COEP:

node -e "require('http').createServer((req,res)=>{res.setHeader('Cross-Origin-Opener-Policy','same-origin');res.setHeader('Cross-Origin-Embedder-Policy','require-corp');res.setHeader('Cross-Origin-Resource-Policy','cross-origin');const f=require('url').parse(req.url).pathname==='/'?'index.html':require('url').parse(req.url).pathname.slice(1);res.writeHead(200);require('fs').createReadStream(f).pipe(res)}).listen(8080)"

Что не подойдёт

python -m http.server 8080 сам по себе не выставит COOP/COEP, но в нашем случае он сработает — service worker сам подкладывает нужные заголовки. Главное — открывать страницу не по file://.
